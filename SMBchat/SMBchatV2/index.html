Discutez avec vos collègues via une interface intuitive. Détection automatique des utilisateurs, messages. Historique suprimé à chaque redémarrage machine.

Transfert ( En cours de dev )

Questions Fréquentes

Trouvez rapidement des réponses à vos interrogations sur SMB chat v_1.2.

Est-ce vraiment sécurisé sans connexion Internet ? +

Absolument. La sécurité est même renforcée : toutes les communications restent strictement sur VOTRE réseau local. Pas de passage par des serveurs externes, pas d'exposition à Internet. Vous avez un contrôle total sur le trafic.

Puis-je l'utiliser sur Mac ou Linux ? +

La version .exe téléchargeable est pour Windows. Cependant, le code source Python fonctionne parfaitement sur Mac et Linux. Des packages natifs pour ces systèmes sont prévus dans notre roadmap. En attendant, vous pouvez exécuter le script Python directement.

Comment contribuer au projet ? +

Plusieurs façons : 1) En tant que développeur : codez de nouvelles fonctionnalités, corrigez des bugs. 2) En tant que designer : améliorez l'interface. 3) En tant qu'utilisateur : testez et rapportez des bugs. 4) En faisant des traductions. Toutes les contributions sont les bienvenues sur GitHub !

Step ue se passe-t-il si mon réseau local tombe en panne ? +

L'application détectera la perte de connexion et se mettra en pause. Vos messages en cours sont sauvegardés localement. Dès que le réseau est rétabli, la détection automatique reprend et vous pouvez continuer à communiquer. L'historique de vos conversations reste disponible.

Pourquoi open source et gratuit ? +

Nous croyons que les outils de communication de base devraient être accessibles à toutes les structures, indépendamment de leur budget. L'open source garantit transparence, sécurité, et permet à la communauté d'améliorer l'outil pour tous. C'est un projet communautaire, pas commercial.
